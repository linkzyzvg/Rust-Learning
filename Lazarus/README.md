# Lazarus

A lightweight, high-performance Discord bot built from scratch using Rust and the `serenity` framework. This project is a learning journey to master asynchronous programming, API integrations, and safe memory management in Rust.

## 🎯 Project Goals

- **Learn Rust Fundamentals:** Master concepts like ownership, borrowing, pattern matching, and error handling.
- **Asynchronous Programming:** Gain hands-on experience with `tokio` and async/await syntax in Rust.
- **Clean Architecture:** Build a modular command handler that makes it easy to add new features.
- **Low Latency & High Efficiency:** Leverage Rust's speed to ensure instant bot responses and minimal memory usage.

## 🚀 Planned Features

### Core Mechanics (Current Focus)
- Ping/Pong command to verify connection and latency.
- Basic logging to track bot events and errors in the console.
- Safe configuration loading using environment variables.

### Utility & Moderation
- User and server information commands.
- Basic moderation tools (kick, ban, clear messages).
- Help menu that dynamically lists available commands.

### Advanced Integrations
- Integration with external APIs (e.g., weather, trivia, or memes).
- Persistent storage using a database like SQLite or PostgreSQL.

## 🤝 Contributing

As this is primarily a personal learning project, contributions are mostly for self-education. However, if you spot a bug, a memory leak, or a way to write more idiomatic Rust, feel free to open an issue or submit a pull request!
